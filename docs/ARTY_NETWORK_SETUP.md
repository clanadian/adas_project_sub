# Arty Z7-20 보드 네트워크 설정

DB·EB PetaLinux 이미지는 DHCP 서버가 없는 실습망(10.10.16.0/24)에서
부팅하면 IPv4 주소를 못 받는다.

## ⚠️ DB는 이제 이 문서가 필요 없다

**DB는 2026-08-20부로 고정 IP가 이미지에 박혀 있다** — rootfs가 initramfs가
아니라 영속 ext4(`root=/dev/mmcblk0p2`)로 바뀌면서
`/etc/network/interfaces`에 `enx020000000020` → `10.10.16.61` 고정 설정이
recipe로 들어갔다. **재부팅해도 유지된다.** 아래 절차는 EB용으로만
남겨둔다(EB는 여전히 `root=/dev/ram0` initramfs라 매 부팅 수동 설정이
필요하다).

## ⚠️ (EB) initramfs라 재부팅하면 사라진다

EB 이미지는 `root=/dev/ram0`(RAM 기반 rootfs)다. 여기서 하는 설정은
**전원을 끄거나 리셋하면 전부 사라진다.** 매 세션 다시 해야 한다.

## 1. 인터페이스 이름 확인

랜선을 꽂거나 뺐다 꽂으면 dmesg에 인터페이스 이름이 그대로 찍힌다.

```text
macb e000b000.ethernet enx020000000020: Link is Up - 1Gbps/Full - flow control off
```

`enx020000000020`처럼 MAC 주소가 이름에 그대로 들어가므로 **보드마다,
케이블을 다시 꽂을 때마다 이름이 다를 수 있다.** 명령을 치기 전에 항상
이 줄을 먼저 확인한다. db와 eb는 PS ENET MAC이 달라서 인터페이스 이름도
다르다.

**입력 중에 이 로그가 끼어들어 명령이 깨질 수 있다** (커널 비동기 메시지가
타이핑 중간에 UART로 섞여 들어옴). 이미 나온 로그에 인터페이스 이름이
보이면, 그 이름을 직접 쓰고 `awk`로 다시 파싱하려 하지 않는다.

## 2. IP 주소 확인 (PC에서 먼저)

같은 실습망을 여러 사람이 쓰므로, 할당하려는 주소가 비어 있는지 보드에서
시도하기 전에 PC에서 먼저 확인한다.

```bash
ping -c1 -W1 10.10.16.6x   # 원하는 주소로 바꿔서
```

응답이 없어야 비어 있는 것이다.

## 3. 보드에서 설정

```sh
IF=enx020000000020                      # 1번에서 확인한 이름
sudo ip addr add 10.10.16.61/24 dev "$IF"
sudo ip route add default via 10.10.16.254
```

`petalinux` 계정은 root가 아니라 `sudo`가 필요하다. `/etc/sudoers.d/99-petalinux`에
`petalinux ALL=(ALL) ALL`로 이미 허용돼 있지만 **비밀번호는 매번 물어본다**
(NOPASSWD 아님) — 로그인 때 새로 설정한 그 비밀번호를 쓴다.

## 4. 확인

```bash
# PC에서
ping -c2 10.10.16.61
```

## 함정 — `sudo ... &`로 백그라운드 띄우지 않는다

서버 등을 백그라운드로 띄우면서 `sudo`를 같이 쓰면, `sudo`가 비밀번호를
터미널에서 읽으려다가 **SIGTTIN으로 그 자리에서 멈춘다** (`Stopped
(SIGTTIN)`). 화면에 `Password:`가 떠도 이미 멈춘 프로세스라 입력이 안
먹힌다.

네트워크가 잡힌 뒤라면 SSH로 두 번째 터미널을 열어서, 그 세션에서 `&`
없이 포그라운드로 띄우는 쪽이 안전하다.

```bash
ssh petalinux@10.10.16.61
```

## 보드별 실측값

| 보드 | 인터페이스 | IP | 콘솔(UART) | 재부팅해도 유지? |
| --- | --- | --- | --- | --- |
| DB | `enx020000000020` | `10.10.16.61` | `/dev/ttyUSB1` | **유지** (recipe로 고정) |
| EB | `enx000a35001e53` | `10.10.16.62` | `/dev/ttyUSB1` | 무효 — 매번 위 절차 반복 |

인터페이스 이름은 MAC 기반이라 고정이지만, **속도(1Gbps/100Mbps)는 그때
꽂은 포트·케이블에 따라 달라진다** — dmesg의 `Link is Up - Ngbps/...`
줄로 매번 확인하고, 문서화된 값으로 단정하지 않는다.

Jetson(`10.10.16.160`)은 DHCP로 자동 할당되므로 이 절차가 필요 없다.
